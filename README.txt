# Poly Tetris

Готовый учебный проект Тетриса на HTML + CSS + JavaScript.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Нажмите «Играть».

Никакие библиотеки и сервер не нужны.

## Что есть
- Главное меню.
- Кнопка «Играть».
- Настройки сложности.
- Нормальная скорость по умолчанию.
- Включение/выключение музыки.
- 3 встроенные мелодии без внешних аудиофайлов.
- Разные скорости падения в зависимости от сложности.
- Следующая фигура.
- Счёт, линии и уровень.
- Пауза.
- Поддержка с управлением.
- Конец игры и перезапуск.
- 12 пентамино из пяти блоков, соответствующие типам фигур на предоставленном изображении.

## Управление
← → — движение  
↑ — поворот  
↓ — ускорение  
Space — мгновенный сброс  
P — пауза  
Esc — меню
